高校教师资格证 · 刷题系统  v1.30.3
========================================

一、这是什么
----------------------------------------
面向高校教师资格证（高校教师岗前培训）四门科目的刷题网页：
  · 高等教育学（713 题）
  · 高等教育心理学（685 题）
  · 高等教育法规（573 题）
  · 教师职业道德修养（436 题）

全库 2407 题，题型只有单选、多选、判断三种（填空、简答已移除），
包含刷题、判分、结果分析、模拟考试、错题本、学习数据备份。

纯静态网页，不需要安装、不需要联网、不需要服务器。


二、怎么打开
----------------------------------------
1. 解压后双击 index.html
2. 推荐用 Chrome / Edge 打开
3. 如果双击后是 Safari 且页面顶部出现黄色提示，说明浏览器禁用了
   本地存储：可以正常刷题，但刷新后进度会丢失。
   解决办法：右键 index.html → 打开方式 → Google Chrome。

也可以在本目录执行：
   python3 -m http.server 8000
然后浏览器访问 http://127.0.0.1:8000/

四、功能入口
----------------------------------------
首页        四个学科轮播 + 模拟考试 / 错题本入口 + 最近记录
题库        学科 → 章节 → 知识点筛选 → 开始练习
刷题        左答题卡、右题面；可标记；自动保存；刷新可继续
模拟考试    高等教育学：70 单选 + 20 多选 = 90 题 / 100 分 / 120 分钟
            高等教育心理学：同上 90 题 / 100 分
            综合（法规+师德）：80 单选 + 30 判断 + 30 多选 = 140 题 / 100 分
            小测试取各板块 40%：36 题 / 40 分、56 题 / 40 分
            倒计时、到点自动交卷、可续考
错题本      答错自动收录；重做答对自动归入「已掌握」
结果页      得分、题型得分、知识点掌握度、逐题解析
备份        顶栏「备份」可导出 / 导入学习 JSON，不含登录态


五、数据保存在哪里
----------------------------------------
所有学习记录保存在浏览器的 localStorage（前缀 gxjszg.）：
  · 关闭浏览器再打开，进度还在
  · 清理浏览器数据 / 换电脑 / 换浏览器，进度会丢失
  · 题库本身在 data/*.js 里，不占浏览器存储，更新题库刷新即可


六、常见问题
----------------------------------------
Q：登录后没进首页？
A：请看页面是否有黄色提示。若有，是浏览器禁用了本地存储，
   换 Chrome 打开，或按上面的方式起本地服务。

Q：页面空白或版本不对？
A：强制刷新（macOS：Cmd + Shift + R）。

Q：想改题目？
A：题库在 data/ 目录，格式见 README.md「题库录入规范」；
   新增学科在 data/subjects.js 注册，并在 index.html 加一行 script。

Q：忘记密码？
A：见第三节，或修改 js/core/auth.js 顶部的 ACCOUNT / PASSWORD。


七、当前版本要点
----------------------------------------
1. 正式卷面只考单选、多选、判断，题库不再包含填空、简答。
2. 考试入口三个：教育学、心理学、综合（法规+师德）。
3. 三张卷各有 5 套完全不重复的组卷容量。
4. 学习数据可导出 / 导入 JSON，导入前会校验，重复导入不重复建会话。
5. 手机答题卡默认收起；错题可按筛选导出 HTML 或打印。
