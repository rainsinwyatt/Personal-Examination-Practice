双击 `index.html` 即可使用，学习记录保存在浏览器本地。

## 一·补充、常见问题

### 点「登录」后没有进入首页？

旧版本在**浏览器禁止本地存储**时会出现这个现象：登录态写不进去，首页守卫又把人踢回登录页。
现在已修复为：

1. 存储层启动时先探测，`localStorage` 不可用就自动切到**内存模式**（本次会话照常刷题）；
2. 登录后会校验登录态是否真的写入，失败会直接在表单下方提示；
3. 内存模式下登录页顶部会显示黄色警示条，登录后提示「临时模式：可以刷题，但刷新后进度会丢失」。

**为什么会禁止本地存储？** 最常见的是 Safari 直接打开本地文件（`file://`）。两个解决办法：

| 办法 | 操作 |
|---|---|
| 换浏览器 | 右键 `index.html` → 打开方式 → Google Chrome |
| 起本地服务 | 在 `exam` 目录执行 `python3 -m http.server 8000`，打开 http://127.0.0.1:8000 |

控制台会打印当前模式，可据此判断：

```text
[exam] 已启动 · 存储模式：localStorage · 题库 2407 题
[exam] 已启动 · 存储模式：内存（临时，刷新后进度丢失） · 题库 2407 题
```

### 页面空白 / 点了没反应？

按 `F12` 看 Console。题库自检：

```js
KY.validate();   // 期望 []
```

## 二·补充、模拟考试规则

| 项 | 大测试 | 小测试 |
|---|---|---|
| 题量 | 学/心理 90 题、综合 140 题 | 各板块 40% 向上取整（36 / 56 题） |
| 卷面 | 学/心理：单选 70 + 多选 20；综合：单选 80 + 判断 30 + 多选 30 | 按各板块 40%（36 / 56 题） |
| 满分 | 100 分 | 40 分 |
| 时长 | 120 分钟 | 48 分钟 |

- **组卷**：按题型分别从该学科题库随机抽题，同一份卷内不重复；某板块题量不足时按实际题量降级并在入口提示。
- **计时**：进入考试即开始倒计时，剩余 10 分钟转黄、5 分钟转红；归零自动交卷（不弹未答确认）。
- **交卷**：手动交卷时会列出未答题号要求确认；交卷后进入结果页，显示「模拟考试」标记与逐题解析。
- **中途离开**：考试记录保留在「进行中」，可从考试中心或首页横幅继续；刷新页面不丢答案，倒计时按真实时间继续走。
- **成绩**：计入「考试记录」，按百分制折算显示，同时保留原始分/卷面总分。

> 小测试满分 40 是按各板块分值累加；百分比分数与卷面分同时展示，不会误读。

## 二·补充、错题本规则

| 动作 | 规则 |
|---|---|
| 自动收录 | 交卷时状态为「错误」的题目写入错题本；同一题重复答错只累加错误次数，不重复建条目 |
| 进入已掌握 | 用错题本发起的重做（`type=wrong`）答对，或手动点「标记掌握」 |
| 移回待掌握 | 已掌握列表里的「移回错题」；重做时又答错也会自动移回并 +1 次错误 |
| 移除 | 从错题本删除该题，历史作答与成绩不受影响 |
| 重做范围 | 单题、整学科、全部待掌握（受当前筛选影响） |
| 排序 | 默认按最近错误时间，可切换为按错误次数 |

## 四、题库录入规范

所有题目都由 `data/schema.js` 的构造器生成，统一字段、统一校验。

```js
// 单选题：id, 题库, 章节, 知识点, 题干, 选项, 答案, 分值, 解析
Q.single('ped-001', 'ped-main', 'c1', 'k1',
  '高等教育与基础教育最本质的区别在于（　　）',
  ['教育对象的年龄更大', '以培养高级专门人才为根本任务', '修业年限更长', '以科学研究为唯一职能'],
  'B', 2, '高等教育的本质属性是培养高级专门人才……'),

// 多选题：答案传数组
Q.multiple('ped-004', 'ped-main', 'c1', 'k1', '高等教育的基本特征包括（　　）',
  ['专业性', '学术性', '终结性', '开放性'], ['A', 'B', 'D'], 3, '……'),

// 判断题：true = 正确
Q.judge('ped-005', 'ped-main', 'c1', 'k1', '高等教育就是大学教育。', false, 1, '……'),

// 填空题：可写多个可接受答案
Q.blank('ped-006', 'ped-main', 'c1', 'k1',
  '高等教育是在完成中等教育基础上实施的____教育。', ['专业', '专门'], 2, '……'),

// 简答题：参考答案 + 采分点（命中比例决定机评分）
Q.short('ped-011', 'ped-main', 'c2', 'k1', '简述高等教育目的……',
  '参考答案全文……', ['高级专门人才', '立德树人', '社会需要', '个体发展'], 10, '……')
```

> 章节 id、知识点 id 只需在**本库内**唯一（如 `c1`、`k1`）；
> `data/index.js` 会自动补成 `c1-k1`，避免不同章节的同名知识点互相覆盖。

新增一门学科只需三步：

1. 在 `data/subjects.js` 里注册学科与题库（章节、知识点）；
2. 新建 `data/<学科>.js` 写题；
3. 在 `index.html` 的 `data/index.js` 之前加一行 `<script>`。

## 五、数据存储

所有学习数据存在 `localStorage`，前缀 `gxjszg.`：

| 键 | 内容 |
|---|---|
| `gxjszg.user` | 登录态 |
| `gxjszg.sessions` | 练习会话（作答、标记、时间），最多 100 条 |
| `gxjszg.results` | 练习结果，最多 100 条 |
| `gxjszg.wrong` | 错题（供 P7 错题本使用） |
| `gxjszg.schema` | 数据结构版本号 |

题库本身不写入 `localStorage`，因此更新题库后刷新即可看到新题。

## 六、自检

浏览器控制台：

```js
KY.validate();          // [] 表示题库完整（题号、答案、章节引用等）
KY.Data.subjects();     // 学科列表
KY.Results.summary();   // 练习次数 / 平均得分 / 累计答题
```

`KY.validate()` 会检查：题号重复、答案不在选项内、章节/知识点不存在、分值为 0、
多选答案不足两个、简答缺采分点等。

## 七、说明

- 题库包含既有导入资料及明确标记的自编练习；本轮585道新增题全部为自编练习。资料标记沿用交接包，不能据此将全库视为已核实的官方真题。

## v1.9.0 新功能与验证

- 顶栏“备份”→“导出学习JSON”：包含练习、成绩、错题、设置，不含登录态；导出前同步保存当前答案。
- “导入学习JSON”先整体验证，再显示确认框合并。本机同名记录优先保留；练习和成绩各最多保留100份。文件格式版本为1、最大10MB。临时存储模式需另存备份，刷新会丢失临时改动。
- 结果页已作答简答题可自评，允许0至题目满分、步长0.5；单题加权分=(原机评分+自评分)/2，保留两位小数。总分、题型、知识点和首页统计同步更新。“恢复机评”可撤回自评。未作答和客观题不开放自评，错题本保留原作答产生的记录。
- 错题本“导出当前错题”下载独立HTML，包含题干、选项、原作答、答案及解析；“打印当前错题”按当前学科/状态筛选生成打印内容。
- 手机≤600px答题卡默认折叠，点击可展开；跳题后收起，返回桌面自动展开。
- 补修临时存储删除后回读旧磁盘值的问题；成绩编号改为随机唯一编号，合并兼容旧编号冲突。
